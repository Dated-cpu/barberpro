# Персональная главная страница для авторизованного клиента

## Что было
Главная страница (`src/app/(public)/page.tsx` + `HeroCinematic`) — статичный маркетинговый hero: логотип-надпись, мастер, рейтинг, теглайн «Ваш образ начинается здесь» и кнопка «Записаться». Для авторизованного клиента главная выглядела точно так же, как для гостя — никакой персональности.

## Что стало
После входа клиент видит на главной **персональную карточку** под CTA hero (новый компонент `PersonalWelcome`):

- **Приветствие по времени суток** — «Доброе утро/день/вечер, {имя}. Рады видеть вас снова» (имя из `auth.me`).
- **Ближайшая запись** — дата, время, услуги (мультиуслуги поддерживаются), барбер (из `appointment.myUpcoming`). Если записи нет — блок скрывается.
- **Быстрые действия** (3 кнопки):
  - «Моя запись» → `/profile?tab=upcoming` (раздел будущих записей)
  - «Записаться снова» → `/booking` (акцентная)
  - «История» → `/profile?tab=history`

Гость и пользователи с ролью ≠ CLIENT видят прежний публичный hero — компонент рендерит `null`.

**States:**
- loading — скелетон карточки (glass, пульсация) без сдвига макета;
- error / неавторизован — карточка не рендерится (гостевой вид), `retry: false` — без лишних запросов;
- empty (нет записей) — блок записи скрыт, быстрые действия остаются.

## Изменённые файлы
| Файл | Изменение |
|------|-----------|
| `src/components/hero/personal-welcome.tsx` | **Новый** — персональная карточка клиента (приветствие, ближайшая запись, быстрые действия, скелетон) |
| `src/components/hero/hero-cinematic.tsx` | В hero под CTA добавлен `<PersonalWelcome />` |

Новых backend-методов не потребовалось: используются существующие `auth.me` (protectedProcedure) и `appointment.myUpcoming` (protectedProcedure, clientId из `ctx.user!.id`).

## Безопасность: не менялось
- Auth (httpOnly cookies), CSRF, RBAC, middleware, аудит, rate-limit — не тронуты.
- Используются только существующие protectedProcedure; ownership-проверки (`assertAppointmentAccess` и др.) не изменялись.
- Никаких новых хранилищ состояния (localStorage/cookies) не добавлено.
