# BarberPro — UX/UI Specification

**Версия:** 1.0  
**Дата:** 2026-07-26  
**Стек:** Next.js 15, TypeScript, Tailwind CSS, Framer Motion, Three.js  
**Стиль:** Luxury Barber — Dark, Warm, Metal, Premium

---

## Creative Direction

```
**Visual style:** Dark luxury — глубокий тёмный фон, тёплый металлический акцент,
минималистичная типографика с премиальными пропорциями.

**Color philosophy:**
- Primary: #0A0A0A (абсолютный чёрный) — основа, глубина, премиум
- Secondary: #1C1C1E (тёмный серый) — карточки, секции, surface
- Accent: #D4A574 (тёплое золото/латунь) — CTA, активные элементы, иконки
- Warm Light: #FFE4C4 (тёплый свет) — glow эффекты, hover
- Metal: #8A8A8E (холодный металл) — границы, разделители
- Text: #F5F5F0 (тёплый белый) — основной текст
- Text muted: #6E6E73 (приглушённый) — secondary text

**Typography:**
- Display: "Playfair Display" — заголовки, элегантная антиква
- Body: "Inter" — читаемость, современный гротеск
- Scale: 1.250 (major third)
- Display font weight: 700 (bold) для hero, 600 для заголовков секций
- Body weight: 400 regular, 500 medium для акцентов

**Spacing:** Базовый юнит 4px. Вертикальный ритм кратен 8px.

**Animation philosophy:**
- Easing: cubic-bezier(0.25, 0.1, 0.25, 1) — Apple-like smooth
- Micro: 200ms (кнопки, toggle, hover)
- Component: 400ms (модалки, карточки, списки)
- Page: 800ms (секции при скролле)
- Stagger: 50ms между детьми
- Scroll: reveal с translateY(40px) → 0 + opacity 0 → 1

**Interaction principles:**
- Каждое действие — отклик в течение 100ms
- Hover — scale + glow (тёплый свет)
- Scroll — параллакс и reveal
- Загрузка — skeleton с shimmer (не спиннеры)
- Успех — morph + checkmark анимация

**Delightful moment:** При подтверждении записи — золотая искра (sparkle particle),
ножницы "смыкаются" в галочку.

**Visual manifesto:**
"Тёмный премиум с тёплым металлическим акцентом. Пользователь чувствует себя
в элитном барбершопе с первой секунды. Ключевой элемент — WebGL сцена с
медленно вращающимися инструментами на тёмном фоне с тёплым боковым светом.
Каждая микро-анимация напоминает физический мир: металл, тепло, точность."
```

## 2. Public Website — страницы

### 2.1 Главная страница (`/`)

**Цель:** WOW-эффект за 3 секунды, запись на услугу, доверие.

**Блоки (сверху вниз):**

| Блок | Описание |
|------|----------|
| **Hero** | WebGL сцена (весь viewport) + лого + CTA "Записаться" + навигация поверх |
| **Services Preview** | 3 карточки топ-услуг с иконками, ценой, длительностью. CTA "Все услуги" |
| **About** | 2 колонки: текст + фото интерьера. Атмосфера, опыт, инструменты |
| **Gallery Preview** | Masonry grid 4 фото. CTA "Смотреть портфолио" |
| **Reviews** | Карусель отзывов (3 visible, dots). Звёзды, имя, дата |
| **CTA Section** | Тёмный фон, крупный текст "Готов к переменам?", кнопка "Записаться онлайн" |
| **Contacts** | Адрес, телефон, карта (статичная), соцсети |

**Анимации:**
- При загрузке: WebGL сцена сразу видна, лого fade in + slide down (600ms), CTA fade in (800ms)
- При скролле: секции reveal снизу (translateY 40px → 0, opacity 0 → 1, stagger 200ms)
- Параллакс: WebGL сцена остаётся фиксированной на hero, плавно размывается при скролле вниз

**CTA:** "Записаться онлайн" — золотая кнопка, при наведении glow тёплым светом

**Mobile:**
- WebGL заменён на статичный градиентный фон (производительность)
- Навигация в bottom bar
- Карточки услуг в horizontal scroll
- Отзывы в swipeable carousel

## 3. Главный экран — WebGL Hero Scene

### Первые 5 секунд

```
00.0s — Чёрный экран. Тишина.
00.5s — Fade in тёмного фона с текстурой (subtle noise overlay).
01.0s — Появляется тёплый боковой свет (слева, под 45°, тёплый amber).
        Медленно зажигается, освещая металлическую поверхность.
01.5s — Из тени проявляются контуры профессиональных инструментов:
        ножницы, опасная бритва, расчёска из чёрного дерева.
        Они медленно вращаются на невидимых опорах.
02.5s — Появляются редкие частицы — дым/пар, подсвеченный тёплым светом.
        Медленно поднимаются вверх, исчезают.
03.0s — Fade in название: "BARBER" (крупно, Playfair Display, кернинг широкий).
03.5s — Под названием: "PRO" (тот же шрифт, золотой акцент D4A574).
04.0s — Снизу появляется подпись: "Премиальный барбершоп" (Inter, светлый).
04.5s — Fade in CTA кнопка: "Записаться онлайн" (золотой outline, hover glow).
05.0s — Fade in навигация (сверху, полупрозрачная).
```

### Поведение

| Событие | Реакция |
|---------|---------|
| Первые 5 сек | Сцена "рождается" из темноты |
| Мышь/курсив | Параллакс микро-сдвиг камеры в сторону курсора |
| Скролл вниз | WebGL сцена медленно размывается (blur + opacity → 0), уступая место контенту |
| Скролл наверх | Сцена восстанавливается |
| Reduced motion | Статичное изображение сцены (один кадр без RAF) |
| Медленный GPU | CSS-градиент вместо WebGL (detect-gpu tier: low → fallback) |
| Mobile | Статичное изображение с parallax эффектом через CSS transform |

### Эмоции

**Первая секунда:** Тайна, ожидание ("что будет?")  
**Вторая-третья:** Восхищение ("вау, как красиво")  
**Четвёртая-пятая:** Доверие ("это премиум, здесь качественно")  
**После 5 секунд:** Желание действий ("где кнопка?")

### Камера

- Позиция: слева-снизу, смотрит вправо-вверх (драматический ракурс)
- Движение: Catmull-Rom сплайн, очень медленный loop (30 секунд полный цикл)
- При скролле: смещение вверх + размытие
- При мыши: микро-сдвиг (max 2% по X/Y)

### Объекты

| Модель | Вращение | Позиция |
|--------|----------|---------|
| Ножницы (раскрытые) | Медленное по Y (360° за 60с) | Центр-справа |
| Опасная бритва | Лёгкое покачивание по X | Слева, ближе к камере |
| Расчёска | Медленное по Z | Справа, дальше |
| Ножницы прямые | Не вращается, легкий float up/down | Задний план |

- Полигоны: < 5K каждая модель
- Текстуры: 1024px, BC7 сжатие (металл, чёрное дерево)

### Свет

- **Key light:** SpotLight слева сверху, тёплый amber (#FFD4A0), интенсивность 0.8
- **Fill light:** PointLight справа, холодный (#8A8A8E), интенсивность 0.2
- **Rim light:** SpotLight сверху сзади, тёплый (#FFE4C4), интенсивность 0.3
- **Environment:** HDR map барбершопа (тёплые тона)
- **Bloom:** Только на металлические блики (intensity 0.3)

### Дым (частицы)

- 30–50 частиц (mobile: 15)
- PointMaterial с мягким градиентом (белый → прозрачный)
- Размер: 0.5–2.0
- Скорость подъёма: очень медленная (0.02)
- Появляются в нижней части сцены, исчезают в верхней
- Подсвечены теплым светом

## 5. Календарь — система записи

### Архитектура данных

```
Для расчёта доступных слотов:

1. Берём WorkingDay для даты:
   - Ищем переопределение (date = targetDate)
   - Если нет — берём шаблон (dayOfWeek)

2. Если isDayOff = true → все слоты недоступны

3. Генерируем слоты: startTime → endTime с шагом 30 мин
   (с учётом breakStart/breakEnd и bufferTime из Settings)

4. Вычитаем занятые Appointment:
   WHERE barberId = ? AND date = ? AND status IN (CONFIRMED, PENDING, IN_PROGRESS)
   Интервалы Appointment.startTime → Appointment.endTime заняты

5. Вычитаем BlockedSlot:
   WHERE barberId = ? AND date диапазон пересекается

6. Для каждого оставшегося слота проверяем:
   - Достаточно ли времени до конца рабочего дня для услуги?
   - Не пересекается ли с перерывом?
```

### Двойная запись — защита

1. **Оптимистичная блокировка:** при нажатии "Подтвердить" слот временно резервируется на 10 минут (создаётся Appointment со статусом PENDING)
2. **Блокировка на уровне БД:** `@@index([barberId, startTime, endTime])` — проверка пересечения через SQL
3. **Race condition:** Если два клиента одновременно выбирают один слот:
   - Первый получает успех
   - Второй получает ошибку "Это время только что заняли" + предложение других слотов
4. **UI:** После выбора времени, слот отображается как "вы выбираете" (желтый / pending) с таймером 10:00

### Конфликт записи

```
Ситуация: Клиент пытается записаться на время, которое уже занято.

UI: Слот серый + 🔴, непрокликабельный.
    При наведении: tooltip "Это время занято. Попробуйте 11:00 или 14:00"

При конфликте (race condition):
    Toast: "Кто-то только что записался на это время"
    Предложения: 3 ближайших свободных слота
    "Выберите другое время: [11:00] [11:30] [14:00]"
```

- Календарь: `role="grid"`, `aria-label="Calendar"`, `aria-selected`
- Tabs: `role="tablist"`, `role="tab"`, `aria-selected`
- Modal: `role="dialog"`, `aria-modal="true"`, `aria-labelledby`
- Toast: `role="alert"`, `aria-live="polite"`
- Carousel: `role="group"`, `aria-roledescription="carousel"`
- Progress bar: `role="progressbar"`, `aria-valuenow`, `aria-valuemin/max`
- Error messages: `role="alert"`, `aria-describedby`
- Loading: `aria-busy="true"`

### Contrast

- Text on dark bg: `#F5F5F0` on `#0A0A0A` → ratio 18.5:1 (AAA)
- Text on card bg: `#F5F5F0` on `#1C1C1E` → ratio 14.8:1 (AAA)
- Muted text: `#8A8A8E` on `#0A0A0A` → ratio 5.2:1 (AA)
- Accent text: `#D4A574` on `#0A0A0A` → ratio 7.1:1 (AA)
- Disabled: `#6E6E73` on `#1C1C1E` → ratio 3.5:1 (minimum)

### Screen Readers

- Все иконки: `aria-hidden="true"` + скрытый text для смысловых
- Изображения: `alt` текст (продуктовые фото — описание, декоративные — `alt=""`)
- Формы: label для каждого поля, error messages в `aria-describedby`
- Динамические обновления: `aria-live="polite"` для toasts и уведомлений
- Календарь: читать дату как "Понедельник, семнадцатое июля"

### Focus States

- Все интерактивные элементы: кастомный focus ring `outline: 2px solid #D4A574; outline-offset: 2px`
- Never `outline: none` без замены
- `:focus-visible` для keyboard, `:focus` only for mouse
- Focus trap в модалках (циклическая навигация)

### Reduced Motion

- `@media (prefers-reduced-motion: reduce)`
- WebGL сцена → статичное изображение (первый кадр)
- Все анимации → snap to final state (0ms transition)
- Parallax → disabled
- Reveal → visible сразу (без анимации)
- Particle systems → disabled
